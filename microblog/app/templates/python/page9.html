1. Введение в простое тестирование

Сегодня мы изучим, как использовать простые утверждения для тестирования функций в Python. Это поможет вам убедиться, что ваш код работает правильно, без необходимости использования классов.

2.1 Описание простого тестирования

Мы будем использовать простые функции и утверждения для проверки корректности работы вашего кода.

Шаг 2: Создание функций для тестирпования

Создайте функции для тестирования в отдельном файле calculator.py.


def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

Эти функции интуитивно понятны. Здесь разделители играют важную роль.

Шаг 1: Импорт необходимых функций

Для начала, нам нужно импортировать функции, которые мы будем тестировать.


from calculator import add, subtract

Эти функции будут протестированы с помощью простых утверждений.

Шаг 3: Подключение модуля для тестирования

unittest` — это стандартный модуль в Python, предоставляющий инструменты для организации и выполнения автоматических тестов кода. Он позволяет разработчикам создавать тесты, которые могут использоваться для проверки правильности и надежности своих программ. `unittest` основан на концепции тестирования с помощью классов и методов, но предоставляет гибкий интерфейс для написания и выполнения тестов


import unittest

Если все утверждения истинны, будет выведено сообщение об успешном прохождении тестов.

Пример тестового файла

Файл test_calculator.py может содержать тесты, как показано ниже:


from calculator import add, subtract

import unittest
assert add(2, 3) == 5, "2 + 3 должно быть равно 5"
assert add(-1, 1) == 0, "-1 + 1 должно быть равно 0"
assert add(0, 10) == 0, "0 + 0 должно быть равно 0"

assert subtract(5, 3) == 2, "5 - 3 должно быть равно 2"
assert subtract(0, 0) == 0, "0 - 0 должно быть равно 0"
assert subtract(10, -5) == 15, "10 - (-5) должно быть равно 15"

print("Все тесты прошли успешно!")

Этот файл можно запускать напрямую для выполнения тестов.

Задание 1: Основная логика выполнения

Запуск тестов позволяет убедиться, что ваш код работает правильно и помогает быстро находить ошибки при изменениях.

3. Возможности расширения

Проверим как работает наша функция, которая загружает карту.


from calculator import add, subtract
import unittest

# ... existing test code ...

def load_maps_from_file(filename):
    maps = []
    current_map = []
    with open(filename, 'r', encoding='utf-8') as file:
        for line in file:
            line = line.strip()  # Удаляем пробелы и символ новой строки
            if len(line) == 0 and current_map:
                maps.append(current_map)
                current_map = []
            elif line:
                current_map.append(line)
        if current_map:
            maps.append(current_map)
    return maps

# Тестирование функции load_maps_from_file без использования классов
# Создаем временный файл для тестирования
with open('test_map.txt', 'w', encoding='utf-8') as f:
    f.write("line1\nline2\n\nline3\nline4\n")

# Ожидаемый результат
output = [['line1', 'line2'], ['line3', 'line4']]

# Вызов функции и проверка
result = load_maps_from_file('test_map.txt')
assert result == output, "Функция должна корректно загружать карты из файла"

print("Все тесты прошли успешно!")
