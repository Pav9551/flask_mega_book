1. Introduction to Scratch

Scratch is a visual programming language that makes it easy to create interactive stories, games, and animations. In this lesson, we'll explore the basics of Scratch programming!

You'll use the Scratch editor to build and test your projects.

2.1 Getting Started with Scratch

Let's start with a simple script. We'll create a script that moves a sprite in a circular motion when the space key is pressed:


- **When I receive [start]**
  - Show
  - Point in direction (90)
  - Go to x: (-187) y: (-70)
  - Forever
    - If <key [space] pressed?> then
      - Repeat (18)
        - Turn (20) degrees
        - Change y by (10)
      - Repeat (18)
        - Turn (20) degrees
        - Change y by (-10)

This script will make the sprite move in a circular pattern when you press the space key. Try it out in the Scratch editor!

2.2 Task 1: Customize the Movement

Modify the script to change the movement speed or direction. You can adjust the values in the "Turn" and "Change y by" blocks to see different effects:


- **When I receive [start]**
  - Show
  - Point in direction (90)
  - Go to x: (-187) y: (-70)
  - Forever
    - If <key [space] pressed?> then
      - Repeat (18)
        - Turn (15) degrees
        - Change y by (15)
      - Repeat (18)
        - Turn (15) degrees
        - Change y by (-15)

Experiment with different values to see how the sprite's movement changes!

Task 2: Add a Variable

In Scratch, you can use variables to store and manipulate data. Let's create a variable to count how many times the sprite moves:


- **When I receive [start]**
  - Set [moveCount v] to (0)
  - Show
  - Go to x: (-187) y: (-70)
  - Forever
    - If <key [space] pressed?> then
      - Change y by (10)
      - Wait (0.1) seconds
      - Change y by (-10)
      - Wait (0.1) seconds
      - Change [moveCount v] by (1)

This script will increase the move count each time the sprite moves. Display the variable to see it in action!

2.4 Using Loops in Scratch

Loops allow you to repeat actions multiple times. Let's use a loop to make the sprite move in a pattern:


- **When I receive [start]**
  - Show
  - Go to x: (-187) y: (-70)
  - Repeat (10)
    - Change y by (10)
    - Wait (0.1) seconds
    - Change y by (-10)
    - Wait (0.1) seconds

This code will make the sprite move up and down 10 times. Try modifying the repeat count to see different patterns!

2.5 Handling Collisions

Let's add a script to handle collisions. If the sprite touches a specific object, it will hide and stop the program:


- **When I receive [start]**
  - Forever
    - If <touching [edge] ?> then
      - Broadcast [end]
      - Hide
      - Hide variable [moveCount v]
      - Broadcast [end]

This script will hide the sprite and stop the program when it touches the edge. Try it out!
