2.1 Getting Started with Scratch

Here's a script that demonstrates cloning and movement:


### Script 1: Main Sprite
- **When I receive [start]**
  - Hide
  - Set [score] to (0)
  - Show variable [score]
  - Forever
    - Create clone of [myself]
    - Wait (1.5) seconds

### Script 2: Clone
- **When I start as a clone**
  - Show
  - Switch costume to [pick random (1) to (10)]
  - Go to x: (212) y: (-4)
  - Glide (1.5) secs to x: (-350) y: (-4)
  - If  then
    - Change [score] by (1)
    - Delete this clone

This script creates clones that move across the screen and increase the score when they reach the edge.
