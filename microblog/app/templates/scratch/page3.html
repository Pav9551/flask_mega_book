2. Custom Block Definition


- **Define [block]**
  - Show
  - Go to x: (7) y: (29)
  - Set effect [brightness] to (10)
  - Forever
    - If <touching [mouse-pointer]?> then
      - Change effect [brightness] by (-15)
      - Wait until <not <touching [mouse-pointer]?>>
      - Change effect [brightness] by (15)

This custom block will make the sprite react to the mouse pointer by changing its brightness.
